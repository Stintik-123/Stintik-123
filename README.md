## Обо мне

Обычный человек из России, который любит три вещи: **код, игры и свободный интернет**.
Пишу боты, собираю веб-проекты, ковыряюсь в консольном homebrew и перевожу open-source на русский.
Всё, что делаю — бесплатное и открытое, потому что знания должны быть доступны каждому.
